# CompilerLens 0.2.2

Status: prepared for release; PyPI publication and the GitHub Release are pending.

## Changes

- Focused operation-lineage IR shows all matching sections with original line numbers,
  while keeping unrelated context collapsed. Native instruction annotations stay with
  their instructions; the full workload pipeline retains its complete IR views.
- Compact `+` controls reveal up to 20 surrounding lines per click. Small direction arrows
  distinguish expansion from either neighbouring section; short gaps use a single button.
  Tooltips and keyboard activation are supported. Full-IR and refocus controls remain.
- Operation Lineage uses the IR viewer and stage timeline only, with no graph-view toggle.
- Regression coverage checks sparse matches, line-number preservation, context expansion,
  stage/operation navigation and no-match fallback. Release documentation targets `main`.

The same frontend is bundled in the CLI wheel and built by source installations. Existing
PyPI installations need an upgrade and viewer restart to receive the updated interface.

## Compatibility

Linux x86-64, glibc 2.35+, with Python 3.10 as the validated interpreter. The wheel bundles
the frontend and LLVM 22 native analyzer; users do not need Node, CMake or an LLVM SDK.
Dependencies and supported model families are unchanged from [0.2.1](0.2.1.md).
Artifact schema 0.7 and lineage schema 1 are unchanged; existing saved runs need no migration
or recompilation for this viewer update. No new model families or tracing guarantees are added.

## Install or upgrade after publication

Stop the running viewer, activate your existing environment, then run:

```bash
python -m pip install --upgrade compilerlens==0.2.2 \
  --index-url https://pypi.org/simple/ --extra-index-url https://download.pytorch.org/whl/cpu
python -m pip check
compilerlens --version
compilerlens doctor
compilerlens view runs/matmul
```

Use your actual saved-run path. To test a fresh capture, choose an unused output directory:

```bash
compilerlens compile --example matmul --out runs/matmul-0.2.2 --lineage required
compilerlens trace runs/matmul-0.2.2 --module model --to asm
compilerlens view runs/matmul-0.2.2
```

For remote servers, follow the README's SSH tunnel instructions.
