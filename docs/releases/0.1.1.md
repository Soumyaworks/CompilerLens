# CompilerLens 0.1.1

Version 0.1.1 packages the latest CLI, LLVM analysis, and documentation changes after
the initial 0.1.0 TestPyPI release. The supported wheel targets Linux x86-64 with
glibc 2.35 or newer; Python 3.10 is the validated interpreter.

## Changes

- Rename the C++ source directory from `native/` to `llvm/` and build it in `build/llvm/`.
- Use lineage terminology in the Python implementation, C++ pass, CLI reports, and frontend.
- Preserve reading of saved runs created with version 0.1.0.
- Add repository, issue tracker, and documentation links to package metadata.
- Document fresh-environment installation, the primary CLI commands, and the combined
  CLI/web compilation and analysis flow. Move planning notes out of the project repository.

## Compatibility

The primary CLI commands and `--lineage` options are unchanged. New runs write
`lineage.json`; the reader still accepts `provenance.json` from 0.1.0. If both files
exist, the new file takes precedence. The artifact schema remains 0.7 and the
analysis sidecar schema remains 1.

Integrations using Python internals should import `compilerlens.lineage` instead of
`compilerlens.provenance`. CLI JSON reports and new `run.json` files use the field
`lineage` instead of `provenance`. The LLVM plugin pass is now named
`compilerlens-lineage`. The private executable remains `compilerlens-native`.

The optional full IREE source-build integration remains unvalidated. The packaged
workflow runs the C++ analysis over IREE's emitted LLVM snapshots.

See the [release checklist](../RELEASING.md) for validation and publication status and
the [CLI guide](../CLI.md) for usage.
